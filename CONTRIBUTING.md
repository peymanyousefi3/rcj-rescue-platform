# Contributing

Developed and maintained by Peyman Yousefi. Contributions are welcome through pull requests.

Fork the repository, create a branch for your change, and open a pull request against `main`. All files are owned by `@peymanyousefi3` in `.github/CODEOWNERS`; changes require his review. Passing automated checks and resolved review conversations are required before merge. New commits dismiss stale approvals. Outside contributions do not grant write access to this repository. The repository owner retains administrator control for his own changes.

For a change, describe the user-facing problem, make the smallest correct implementation, and run the relevant tests. Preserve team privacy, server-side authorization, deadline checks, accessible controls and explicit release decisions. Add a regression test for behavior that could expose data or calculate incorrect results.

Use fictional fixtures. Never commit accounts, uploaded competition files, passwords, keys, environment files, database copies or production operational notes. Keep third-party copyright and license notices intact. Contributions to project-owned code use the MIT License.
