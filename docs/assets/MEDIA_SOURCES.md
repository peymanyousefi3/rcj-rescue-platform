# Demonstration media provenance

The README GIFs show real browser interfaces and Rescue Simulation scenes. Public replay and map assets originate from the publicly released RCJRescue ASR 2026 demonstration. Team workflow captures use fictional local examples or isolated demonstration workflows; no private submission contents or operational credentials are included.

- Public replay events, linked complaint and score matrix: current local platform feature branch, filmed 30 October 2026.
- Branding: isolated RCJ-themed, read-only demo; temporary edits reset on reload.
- Field, submissions, calendar, announcements, file delivery and SuperTeams: existing ASR demonstration footage, selected to show the corresponding workflow.

These are looping GIFs, not embedded video players; GitHub supports animated GIF images but not an iframe video embed in a README. The narrated video links to YouTube. A static companion is available in docs/PROJECT_OVERVIEW.pdf.
